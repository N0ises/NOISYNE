
# Support

Version: 2.0

Status: ACTIVE

---

# Purpose

This document explains how users, contributors, researchers and developers can
receive help regarding PHASENOX.

---

# Project Scope

PHASENOX is an Audio Intelligence System focused on professional audio,
engineering, AI reasoning and future autonomous production workflows.

Support is provided for:

- Installation
- Configuration
- Development
- Architecture
- AI Features
- Audio Analysis
- Engineering Reports
- Documentation

# Bug Reports

Include:

- PHASENOX version
- Operating system
- Python version
- Hardware (CPU / GPU)
- Steps to reproduce
- Expected behavior
- Actual behavior
- Logs (if available)

---

# Feature Requests

Describe:

- Problem
- Proposed solution
- Engineering motivation
- Expected benefit

Architecture-first proposals are preferred.

---

# Documentation Issues

If documentation is inaccurate or incomplete, please report:

- File name
- Section
- Suggested improvement

Documentation is treated as part of the product.

---

# AI Limitations

AI-generated recommendations should always be reviewed by an engineer before
being used in production.

Human expertise remains the final authority.

---

# Community Principles

- Be respectful.
- Be constructive.
- Share reproducible examples.
- Prefer evidence over assumptions.

---

# Long-Term Goal

Provide a professional support experience suitable for researchers,
developers and audio engineers building on top of PHASENOX.
