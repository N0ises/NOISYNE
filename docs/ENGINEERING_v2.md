# Engineering Mindset

We optimize for long-term evolution, not short-term implementation speed.

Architecture always has higher priority than features.

# Mission

Build an Audio Intelligence System combining DSP, AI, psychoacoustics and professional engineering.

# AI Rules

Every recommendation should contain:

- Observation
- Evidence
- Reasoning
- Confidence
- Recommendation

# Coding Rules

Prefer:

- Explicit interfaces
- Type hints
- Small modules
- Clear names

Avoid:

- Circular imports
- Hidden dependencies
- Duplicate business logic
- Magic values

# Performance

Measure before optimizing.

Cache expensive computations.

# Final Principle

Good software evolves confidently because its architecture remains stable.
