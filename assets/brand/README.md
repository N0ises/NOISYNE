# PHASENØX Brand Package

Production-oriented identity assets for PHASENØX. This revision preserves the restrained NØISYNE visual DNA while making the identity darker, more cinematic and explicitly connected to audio intelligence. The eye is integrated as the Ø/O, not used as a separate mascot.

Primary assets live in `master/`. Hero/social assets add sparse waveform, phase and signal motifs. `guidelines/` defines usage rules and design tokens.
